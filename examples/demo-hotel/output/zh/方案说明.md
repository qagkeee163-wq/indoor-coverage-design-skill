- 主机 Hi23-6S-PLUS CE 23 dBm: 1
- 吸顶天线: 3;  壁挂板状天线: 3;  施主天线: 1
- 耦合器：5 dB × 0, 8 dB × 1, 10 dB × 0
- 功分器：1:2 × 0, 1:3 × 2, 1:4 × 0

## 设计检查提示（内部）

- [M1] splitter S1 outputs differ a lot (3–14 m): a coupler is usually better when one branch is much longer
- [M1] splitter S2 outputs differ a lot (15–26 m): a coupler is usually better when one branch is much longer
- [M1] antenna B3 @1800 MHz 0.98 dBm is close to the limit (0.98 dB above 0.0 dBm) – tell the user and offer one recalculated alternative
